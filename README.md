# Moisés Runner

Juego runner bíblico en Three.js, ambientado en el antiguo Egipto.

## Ejecutar

Abre `index.html` mediante un servidor estático local o activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main / root**.

Controles: flechas o WASD; en móvil, desliza.

El proyecto carga Three.js desde jsDelivr y la tipografía desde Google Fonts, por lo que requiere conexión a Internet.
